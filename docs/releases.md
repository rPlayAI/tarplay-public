# Release notes

## v1.0-beta.2 (2026-11-05)

- **PhoneAuto 1.1 (4):**
  - Maps search opens in portrait (#6). Android Auto only allows it when its screen is wide enough, so the portrait UI is a little smaller.
  - New **Larger icons and text** switch. In portrait, Maps search may not open with it on.
  - Foldables: with Portrait mode on, the inner screen is filled in portrait instead of a small landscape box.
  - The ✕ button fades out after a few seconds so it doesn't cover Android Auto's clock and buttons (#4, #9). Touch the screen to bring it back.
  - Start says so when Android Auto isn't installed or is turned off on the phone.
  - Stops working on 2027-02-03. Installs over beta 1 and keeps your settings.

CarCast Launcher and TarPlay Tesla are unchanged; get them from beta 1.

## TarPlay Tesla 1.0 beta 1 (2026-10-23)

- **TarPlay Tesla 1.0 (3):** first public build. Android Auto in the Tesla browser at https://v.tarplay.com:8081 over the phone's hotspot. One-tap start, automatic reconnect, one viewer at a time. Stops working on 2027-01-19.

## v1.0-beta.1 (2026-10-22)

- **PhoneAuto 1.0 (3):** portrait mode now works on Android 17. Smaller download (1.8 MB). Removed the debug overlay and the touch dead zone on the right edge of the screen.
- **CarCast Launcher 1.0 (2):** first public build.

Both builds stop working on 2027-01-19.
