# Release notes

## TarPlay Tesla 1.0 beta 1 (2026-10-23)

- **TarPlay Tesla 1.0 (3):** first public build. Android Auto in the Tesla browser at https://v.tarplay.com:8081 over the phone's hotspot. One-tap start, automatic reconnect, one viewer at a time. Stops working on 2027-01-19.

## v1.0-beta.1 (2026-10-22)

- **PhoneAuto 1.0 (3):** portrait mode now works on Android 17. Smaller download (1.8 MB). Removed the debug overlay and the touch dead zone on the right edge of the screen.
- **CarCast Launcher 1.0 (2):** first public build.

Both builds stop working on 2027-01-19.
